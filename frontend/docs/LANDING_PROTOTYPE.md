# Studere landing prototype (HTML)

Self-contained dark landing prototype.

- Open `/landing-prototype.html` (or `frontend/public/landing-prototype.html`) in a browser.
- Needs network for Google Fonts + GSAP CDN.
- Hero storytelling stays JS/GSAP; progress bar uses CSS `animation-timeline: scroll()` when supported.

Port into `frontend/components/landing-page.tsx` when integrating into Next.
